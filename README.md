# 🚨 TG Alarm — Системный Будильник Критических Уведомлений Telegram

Система автоматического развертывания и мониторинга для Telegram. Если важный бот присылает сообщение (сигнал, алерт, отстук), система гарантированно **будит пользователя Telegram-звонком со 2-го аккаунта** и отправляет приоритетное звуковое уведомление.

---

## 🛠 Компоненты системы

1. **`monitor.py` (Userbot)** — Монитор сообщений на базе MTProto (Telethon). Отслеживает все входящие сообщения от указанного бота в реальном времени.
2. **`admin_bot.py` (Admin Bot API)** — Интерактивный Telegram-бот для управления режимом:
   - 💤 **Режим СНА (`is_sleeping = True`)**: Входящие от бота вызывают громкий звонок + уведомление.
   - ☀️ **Режим БОДРСТВОВАНИЯ (`is_sleeping = False`)**: Звонки отключены, только стандартные сообщения.
   - ⏳ **Таймеры "Не спать" (2ч / 4ч / 8ч)**: Автоматическое переключение обратно в режим сна.
3. **`alerter.py` (Caller Service)** — Модуль совершения Telegram-звонков и запаса на Twilio.
4. **`ops/`** — Набор батников для удобного управления VPS с Windows десктопа.

## 🚀 Быстрый старт и настройка

### Шаг 1. Настройка переменных (`.env`)
Скопируйте `.env.example` в `.env` и заполните:

```env
# Ваш основной аккаунт Telegram (для мониторинга)
TG_API_ID=12345678
TG_API_HASH=your_api_hash
TG_PHONE=+380XXXXXXXXX

# Имя или ID бота, которого отслеживаем
TARGET_BOT_USERNAME=@important_signal_bot

# Бот управления (токен из @BotFather)
ADMIN_BOT_TOKEN=1234567890:AAA...
ADMIN_CHAT_ID=ваш_telegram_user_id

# Второй аккаунт Telegram (для совершения входящих звонков)
CALLER_API_ID=12345678
CALLER_API_HASH=your_api_hash
CALLER_PHONE=+380YYYYYYYYY
```

---

### Шаг 2. Одноразовая авторизация аккаунтов

Перед первой отправкой на VPS запустите локально script авторизации:

```bash
python setup_auth.py
```

Вам придут проверочные коды в Telegram для основного и второго аккаунтов. Скрипт создаст файлы сессий `monitor_session.session` и `caller_session.session`.

---

### Шаг 3. Деплой на Linux VPS

Для автоматической загрузки и запуска под PM2 запустите:

```bash
python deploy_remote.py
# или используйте ops/deploy.bat
```

Скрипт сам установит Python, Node.js, PM2, зависимости и запустит 2 процесса:
- `tgalarm-monitor`
- `tgalarm-adminbot`

## 📱 Управление через Telegram Admin Bot

Откройте вашего бота в Telegram и отправьте `/start`.
Вы увидите меню:

- **[ ☀️ Переключить на: НЕ СПЛЮ ]** / **[ 💤 Переключить на: СПЛЮ ]**
- **[ ⏳ Не спать 2ч ]** / **[ ⏳ Не спать 4ч ]** / **[ ⏳ Не спать 8ч ]**
- **[ 🔄 Обновить статус ]**

Статистика и текущий статус обновляются в реальном времени!
